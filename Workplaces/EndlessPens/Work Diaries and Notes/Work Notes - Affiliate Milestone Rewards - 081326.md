# Affiliate Milestone Rewards

>[!tip] From Raqui:
>I've looked into UpPromote and found that we cannot automate an email for the affiliates for a Milestone Pen, regardless of set thresholds :( The only available reward I've found that allows us to set thresholds is the "[Bonuses](https://admin.shopify.com/store/endlesspens/apps/affliate-by-secomapp/admin/motivation/bonus)" feature. Creating a [new bonus](https://admin.shopify.com/store/endlesspens/apps/affliate-by-secomapp/admin/motivation/bonus/create) requires us to choose a target type (Number of referrals, Total commission, or Total sales), and a target amount. It also allows us to set a period for the bonus (One-time, Monthly, Quarterly, Yearly).
>
>
I've also looked into the "[Gifts](https://admin.shopify.com/store/endlesspens/apps/affliate-by-secomapp/admin/motivation/gifts)" feature, and it seems to only allow us to set a welcome gift.
>
>
> Currently, our only recourse for determining whether an affiliate should get a Milestone Pen is by manually exporting the entire referral list, and checking which affiliates have reached our set threshold.
>
>
> **If we decide to move forward with this method, we could:**
> 1. Export all referrals monthly
> 2. Use excel to sum up each affiliate's number of referrals, total commission, or total sales
> 3. Determine which affiliates qualify for a Milestone Pen
> 4. Manually send the Milestone Pen email to the affiliate
>
